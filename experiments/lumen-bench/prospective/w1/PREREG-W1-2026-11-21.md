# Pre-registration W1 (2026-11-21): prospective LUMEN forecasts for LN trials without posted results

## Why
W1 asks for forecasts frozen BEFORE results are read. The ClinicalTrials.gov check today (API v2,
condition "lupus nephritis", HasResults=true, sorted by results-first-posted date) found **no LN trial with
results newer than the 2026-11-21 harvest**: all 45 are already in `lupus_with_results.json.gz`
(newest results post: NCT02682407 narsoplimab, 2026-03-30). So nothing can be scored today.
Instead this run freezes forecasts for the randomised placebo-controlled add-on LN trials that have **no
results posted** (status completed, terminated, active-not-recruiting or recruiting), so later W1 runs can
score them as results appear. This is the first truly prospective test of the forecaster.

## Forecast (frozen, `w1_frozen_2026-11-21.json`)
Prior-only `lumen_forecast` (no early read-out exists): same molecule > same exact target string > pooled.
Exact target matching only (BAFF-R is not BAFF; CD40L is not CD40). An "axis" anchor is recorded as a
secondary variant for ianalumab (BAFF) and dazodalibep (CD40) but is NOT the primary forecast.
Quantity: log odds ratio, drug vs placebo/control, of the trial's protocol-defined complete renal response
(CRR) at its primary timepoint, 0.5 continuity correction.

## Scoring rule (fixed now)
- A trial is scorable when CT.gov (or a peer-reviewed paper) posts CRR counts by arm. If its primary
  endpoint is not CRR, use a CRR secondary if present; otherwise it is listed as unscorable, not dropped.
- Multi-dose trials: each dose arm vs control scored, trial-weighted equally.
- Baselines: null (log OR 0) and pooled mean of all arms (0.342 today).
- Decisive comparison: the **anchored** trials (IRIS, QLG1074, obinutuzumab paediatric, MIL62), because for
  un-anchored trials the forecaster equals the pooled baseline by construction.
- **PASS** once >= 3 anchored trials are scored if: (a) >= 80% of all scored arms fall in the 95% interval,
  and (b) forecaster IV-weighted MSE on anchored arms <= pooled-mean baseline and < null.
- FAIL otherwise. Partial scores are reported as they arrive, labelled "interim".
